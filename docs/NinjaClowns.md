## Extra content

What the core adds for this game:

- **Audio** (FM + PCM, FM only, PCM only): mixes the two sound chips.
- **Button layout**: Punch, Kick, Throw, Start, Coin, Service, the same for both players.

The [core-wide features](../README.md#features) (CRT Adjust, NVRAM saving, Service Mode and the rest) apply to every game.

## Controls

| Input | Use |
|---|---|
| Stick | Move (8-way) |
| A | Punch |
| B | Kick |
| X | Throw |
| Start | Start |
| R / L | Coin / Service (the second controller's Coin is coin slot 2) |

The same layout works for both players. The board is the 68000 variant (lower board P/N 1029 REV3A), with a 16 KB NVRAM.
